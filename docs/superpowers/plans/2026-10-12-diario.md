# Linguagem visual "Diário": plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar a linguagem visual das quatro páginas do site pela do "Diário" (serifada, preto sobre papel, fios), sem mudar dados nem regras.

**Architecture:** A marcação e os módulos de `site/src` continuam os mesmos; mudam poucos pontos de marcação (cabeçalho, título do dia, lista de viagens), as fontes hospedadas e a folha `site/style.css`, que é reescrita. O gerador do mapa ganha a divisão do anel que cruza a borda.

**Tech Stack:** TypeScript estrito, Vite, vitest com jsdom e axe-core, CSS puro. Nenhuma dependência nova.

**Spec:** `docs/superpowers/specs/2026-10-12-diario-design.md`. Referências visuais: capa https://claude.ai/artifact/5zRgAau386pWQgkatxXB7H e registros https://claude.ai/artifact/2edrLrxGaqsCo3ywaYq7hX (direção "2 · Diário").

## Global Constraints

- Branch `redesenho`, nesta pasta de trabalho. Nada vai para `main` nem para o GitHub neste plano.
- Texto vindo de `data/` entra no DOM só por `textContent`/`append(string)`. Nunca `innerHTML`.
- Nenhum atributo `style`, nenhum `<style>`, nenhum manipulador inline: a CSP proíbe e os testes conferem. Isso inclui `elemento.style.setProperty(...)`.
- Caminhos sempre relativos. Links só `https`.
- Nenhuma cor fora dos blocos `:root` de `site/style.css` (o teste de contraste falha se houver).
- `transition` e `animation` só dentro de `@media (prefers-reduced-motion: no-preference)`. Só animam `opacity`, `transform`, cores e `stroke-dashoffset`.
- Fontes: `.woff2`, subconjunto latino, até 90 000 bytes no total.
- Não editar `data/` nem `site/src/mapa-contorno.ts` à mão.
- Textos de interface, nomes de teste e commits em português do Brasil. Commits `tipo(escopo): resumo`, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Antes de dar uma tarefa por pronta: `npm run typecheck && npm test`. Na última tarefa, também `npm run build`.

## Desvios do spec, decididos ao ler o código

- **Dependências**: o spec fala em trocar pacotes `@fontsource`. Eles não estão no `package.json`: as fontes atuais foram copiadas com `npm pack`. O plano segue a mesma prática e não toca em `package.json`.
- **Largura**: todas as páginas usam 62rem. Em Registros a coluna "Próximos compromissos" precisa do espaço; o texto corrido é limitado por `max-width` em caracteres.
- **Fontes do registro**: o selo, o link permanente e a lista de fontes mantêm a ordem atual no DOM (o foco segue a ordem visual). O selo fica em itálico, sem dois-pontos, e os links vão na linha de baixo.
- **Título da capa**: o `<h1>` de `index.html` continua no `main`, visível só para leitor de tela; quem vê a tela lê o nome do site no cabeçalho.
- **Rotas do mapa**: desenham-se todas juntas. Escalonar exigiria `style` por elemento, que a CSP proíbe.

## Review Focus

1. Título de dia lido duas vezes por leitor de tela (texto oculto mais partes visuais): as partes visuais têm `aria-hidden`. Teste na tarefa 3.
2. Âncora de link permanente escondida atrás do título fixo do dia no celular: `scroll-margin-top`. Teste de CSS na tarefa 6 e conferência manual.
3. Página sem JavaScript: a faixa de data do cabeçalho fica vazia e não pode deixar dois fios soltos. Regra `.datado:empty`-equivalente na tarefa 6 e conferência manual.
4. Uma só cidade ou um só país no resumo das viagens ("1 cidade em 1 país"). Teste na tarefa 4.
5. Movimento reduzido: nada anima e as rotas do mapa aparecem inteiras. Teste de CSS na tarefa 6 e conferência manual.

```js
// Um anel que cruza o meridiano de 180° (a ponta leste da Rússia) tem dois saltos de um lado ao outro do mapa.
// Dividido nesses dois pontos, vira dois anéis, um em cada borda.
function dividirNaBorda(pontos) {
  const saltos = [];
  pontos.forEach(([x], i) => {
    const [xSeguinte] = pontos[(i + 1) % pontos.length];
    if (Math.abs(xSeguinte - x) > LARGURA / 2) saltos.push(i);
  });
  if (saltos.length !== 2) return [pontos];
  const [i, j] = saltos;
  return [pontos.slice(i + 1, j + 1), [...pontos.slice(j + 1), ...pontos.slice(0, i + 1)]];
}
```

- [ ] **Step 3: `tituloDoDia` em `site/src/render.ts`**

Depois de `formatarDataCurta`:

```ts
/**
 * Título de um dia: a data por extenso para leitor de tela e as partes que a tela mostra separadas
 * (numeral, mês e ano, dia da semana). As partes visuais ficam fora da leitura para a data não ser dita duas vezes.
 */
export function tituloDoDia(doc: Document, data: string): HTMLElement {
  const longa = formatarDataLonga(data);
  const [semana, resto] = longa.split(', ');
  const visual = (classe: string, texto: string) => el(doc, 'span', { class: classe, 'aria-hidden': 'true' }, texto);
  return el(doc, 'time', { datetime: data },
    el(doc, 'span', { class: 'so-leitor' }, longa),
    visual('dia-n', data.slice(8)),
    visual('dia-mes-ano', resto.replace(/^\d+ /, '')),
    visual('dia-semana', semana));
}
```
